# 账户概览

## 触发条件
用户要求“账户概览”、“余额和最近流水一起看”，但没有要求转账或修改账户。

## 只读步骤
1. MCP `bank_get_balance()` 查询本人当前模拟账户余额。
2. MCP `bank_get_transactions()` 查询本人可见的模拟交易流水。
3. 汇总当前余额和返回的记录数量；仅使用 Java 原始结果。

## 边界
不推算不存在的账户状态；不查看其他用户数据；不修改账户、卡片或资金。
