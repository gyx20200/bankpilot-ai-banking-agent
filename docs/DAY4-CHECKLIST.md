## 联调验收演示顺序
1. 初始化数据库，记录双方账户余额
2. 发送“给李四转200元” -> `PENDING_APPROVAL`；余额不变
3. 点击“确认并授权” -> `AUTHORIZED`；余额仍不变
4. 点击“执行模拟转账” -> `SUCCESS`，查看交易流水及余额变化
5. 刷新状态，确认后台订单 `SUCCESS`；二次执行不得重复扣款
6. 重置数据或切换测试场景，发起 1500 元 -> 红色强验证
7. 验证错误码无效，合法演示验证后才能授权
8. 取消未执行订单，验证不可再执行
9. 保存界面、数据库变更、审计日志截图

**注意：** Mock 成功只能证明界面/网关流程，不能证明 Java 的数据库事务和真实身份认证通过验收。
